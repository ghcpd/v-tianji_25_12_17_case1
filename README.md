# Novel Reader

A small frontend-only novel reading web app built with Vite + React + TypeScript. Features: browse novels, read chapters, track reading progress, bookmarks, bookshelf, theme switching, font-size control. Uses in-memory mock data.

Commands:

- Install: npm install
- Dev server: npm run dev
- Run tests: npm run test
- Build: npm run build

This project includes unit tests (Vitest + Testing Library) and uses Tailwind CSS for styling.
